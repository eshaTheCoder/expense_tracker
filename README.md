# 💰 Python Expense Tracker

A simple and easy-to-use Python project to manage your daily expenses.

## ✨ Features
- Add daily expenses
- View all expenses
- Calculate total spending
- Save data in a file
- Monthly expense report

## 🛠️ Technologies Used
- Python 3
- File Handling

## 🚀 How to Run
1. Download the file `main.py`
2. Run in terminal: `python main.py`
3. Follow the instructions
