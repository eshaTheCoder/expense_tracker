# 💰 Expense Tracker v2.0 - Python OOP

A professional, feature-rich expense tracker rebuilt from scratch with Object-Oriented Programming principles.

### 🔄 v1.0 vs v2.0 - My Growth Journey
**v1.0 (Old):** Basic functional version with 4 features - single file, title-based deletion.
**v2.0 (Current):** Professional OOP version with 10+ features, modular design, and bug fixes.

### ✨ Features in v2.0
- ✅ Proper OOP Structure (3 Files: Expense, Tracker, main)
- ✅ Budget Tracking with Smart Alerts (80% warning, 100% exceeded)
- ✅ Search, Filter by Category & Date Handling
- ✅ Category-wise Summary & Analytics
- ✅ Update Expense & Safe Index-based Deletion
- ✅ Custom Dunder Methods (__str__, __add__, __gt__)
- ✅ Robust Error Handling & Float Amount Support
- ✅ CSV Persistence with auto-save

### 🚀 How to Run

python main.py
